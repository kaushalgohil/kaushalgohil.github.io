# Kaushal A. Gohil — Portfolio

Static personal portfolio and blog for GitHub Pages.

## GitHub Pages
Use the repository `kaushalgohil/kaushalgohil.github.io`, keep these files at the repository root, and set GitHub Pages to deploy from `main` / root.

## Structure
- `index.html` — main portfolio
- `style.css` — site styling
- `assets/kaushal.jpg` — profile photo
- `blog/index.html` — blog index
- `blog/first-post.html` — starter post
